# Лабораторная 1


Реализованно: простейшая регистрация и сохранение авторизации с помощью cookie, а также запрос на внешний API

- Регистрация и авторизация с использованием cookie.
- Получение данных (случайных) о пользователе с внешнего API[^1].

[^1]: Двойной запрос на получение данных пользователя происходит из-за StrictMode ввиду двойной перерисовки компонентов.
